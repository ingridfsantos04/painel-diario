# ⚡ FlowPulse — Painel Executivo Diário

> Workspace moderno de produtividade pessoal, checklist de tarefas e acompanhamento analítico de rotina.

---

## 📌 Sobre o Projeto

O **FlowPulse** é uma aplicação desenvolvida para centralizar a rotina diária em um único painel executivo. O sistema permite organizar tarefas diárias, registrar notas rápidas e acompanhar gráficos de evolução e produtividade ao longo do tempo.

---

## ✨ Funcionalidades Principais

- **🎯 Central do Dia:** Gestão diária de tarefas com divisão visual entre demandas pendentes e concluídas.
- **🏷️ Categorias & Prioridades:** Classificação por Trabalho, Estudos ou Pessoal, além de níveis de prioridade (Alta, Média, Baixa).
- **⚡ Bloco de Pensamento Rápido:** Área integrada para colar links, rascunhos e lembretes rápidos sem sair da tela principal.
- **📊 Relatório de Evolução:** Gráficos interativos (distribuição por categoria e consistência de entregas ao longo dos dias).
- **📝 Caderno de Notas:** Registro e histórico de anotações e resumos de reuniões.
- **💾 Persistência Local:** Salvamento automático dos dados em formato JSON.

## 🛠️ Tecnologias Utilizadas

- **[Python](https://www.python.org/)** — Linguagem principal

## 🚀 Como Executar o Projeto Localmente

### 1. Clonar o repositório
```bash
git clone https://github.com/ingridfsantos04/painel-diario.git
```

### 2. Entrar na pasta
```bash
cd painel-diario
```

### 3. Instalar as dependências
```bash
pip install -r requirements.txt
```

### 4. Rodar a aplicação
```bash
python -m streamlit run app.py
```
